# Space Exploration Quiz

A single-file, dependency-free quiz about space exploration: ten questions, a progress bar, animated green/red answer feedback, and a result screen with an emoji reaction.

## Run

Open `index.html` in any modern browser. No build or server needed.

## Controls

- Click an option, or press `1`–`4` to answer.
- `↑`/`↓` move between options; `Enter` advances to the next question.
